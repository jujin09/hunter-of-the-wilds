# Hunter of the Wilds — 웹 + PWA 배포 가이드

이 폴더를 그대로 Vercel에 올리면 웹에서 바로 플레이할 수 있고, 휴대폰·PC에 앱처럼 설치(PWA)할 수 있어요.
Supabase를 연결하면 이메일 로그인과 계정 세이브, 오프라인 동기화가 켜져요.
**Supabase를 연결하지 않아도 게임은 동작해요.** 그 경우 진행 상황은 각자 브라우저에만 저장돼요.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 본체 (모든 코드가 이 파일 하나에 있음) |
| `config.js` | Supabase 주소와 공개 키를 넣는 곳 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 전체화면 설정 (PWA) |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `vercel.json` | 캐시 설정 (업데이트가 바로 반영되도록) |
| `supabase.sql` | 세이브 테이블, 보안 규칙, 저장 함수 |

---

## 1단계. Supabase 프로젝트 만들기 (계정 기능을 쓸 때만)

1. https://supabase.com 에 가입하고 **New project**를 만들어요. (지역은 Northeast Asia (Seoul) 추천)
2. 왼쪽 메뉴 **SQL Editor → New query**를 열고, `supabase.sql` 내용을 전부 붙여 넣은 뒤 **Run**을 눌러요.
   - `game_saves`(세이브), `game_save_backups`(백업) 테이블과 `save_game` 함수가 만들어져요.
   - RLS(행 단위 보안)가 켜져서, 로그인한 사람은 **자기 세이브만** 읽고 쓸 수 있어요.

## 2단계. 이메일 로그인 설정

1. **Authentication → Providers → Email**이 켜져 있는지 확인해요. (기본으로 켜져 있음)
2. **Authentication → URL Configuration**에서
   - **Site URL**: 나중에 Vercel 주소 (예: `https://hunter-of-the-wilds.vercel.app`)
   - **Redirect URLs**: 같은 주소를 추가
   - 회원가입 확인 메일과 비밀번호 재설정 메일의 링크가 이 주소로 돌아와요.
3. 테스트할 때 메일 인증이 번거로우면 **Authentication → Providers → Email → Confirm email**을 잠시 꺼도 돼요.

## 3단계. config.js 채우기

**Project Settings → API**에서 두 값을 복사해 `config.js`에 넣어요.

```js
window.WH_CONFIG = {
  supabaseUrl: "https://xxxxxxxx.supabase.co",
  supabaseAnonKey: "eyJhbGciOi..."   // anon public 키
};
```

> ⚠ **service_role 키는 절대 넣지 마세요.** anon 키는 공개돼도 괜찮게 설계돼 있어요(RLS가 지켜 줌). service_role 키는 모든 보안을 무시하는 관리자 키예요.

## 4단계. Vercel에 배포

**방법 A — GitHub 연결 (추천, 업데이트가 가장 쉬움)**
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 전부 올려요.
2. https://vercel.com → **Add New → Project** → 그 저장소를 **Import** → 설정은 건드리지 말고 **Deploy**.
3. 끝나면 `https://프로젝트이름.vercel.app` 주소가 생겨요. 이 주소를 2단계의 Site URL에 넣어요.

**방법 B — 드래그 앤 드롭**
1. `npm i -g vercel` 설치 후 이 폴더에서 `vercel` 명령 실행, 질문에 엔터만 눌러도 배포돼요.

## 5단계. 앱으로 설치 (PWA)

- **안드로이드 크롬 / PC 크롬·엣지**: 길드 화면의 **📲 앱 설치** 버튼, 또는 주소창의 설치 아이콘
- **아이폰·아이패드**: Safari로 열고 **공유 버튼 → 홈 화면에 추가**
- 설치하면 아이콘이 생기고, 주소창 없이 전체 화면으로 열려요. 한 번 열어 둔 뒤에는 **인터넷 없이도 실행**돼요.

---

## 업데이트하는 법

1. 바뀐 `index.html`(필요하면 다른 파일도)을 GitHub 저장소에 덮어써서 올려요.
2. Vercel이 1~2분 안에 자동으로 다시 배포해요.
3. 플레이어는 다음에 게임을 열 때 자동으로 새 버전을 받아요. 열려 있는 중이면 화면 아래에 **"새 버전이 나왔어요 · 새로고침"** 알림이 떠요.

설치 파일을 다시 배포할 필요가 없어요. `sw.js`의 `VERSION`을 올리면 예전 캐시가 깔끔히 정리돼요(안 올려도 동작함).

## 저장·동기화가 동작하는 방식

| 상황 | 동작 |
|---|---|
| 플레이 중 | 진행이 바뀔 때마다 **기기에 즉시 저장** → 2초 뒤 서버로 전송, 30초마다 한 번 더 확인 |
| 앱을 닫거나 다른 앱으로 전환 | 남은 변경을 바로 서버로 전송 |
| 인터넷 끊김 | 계속 플레이 가능. 기기에 저장해 두고 **📴 오프라인** 표시 |
| 인터넷 복구 | 자동으로 서버에 올리고 **☁ 동기화됨** 표시 |
| 다른 기기에서 먼저 저장해 둔 경우 | 덮어쓰지 않고 **"저장 데이터가 서로 달라요"** 창에서 고르게 함. 고르지 않은 쪽은 백업으로 보관 |
| 게스트로 하다가 로그인 | 계정에 세이브가 없으면 지금 진행을 그대로 올림. 있으면 고르게 함 |
| 로그아웃 | 아직 못 올린 진행이 있으면 경고. 로그아웃 후에는 빈 게스트 상태로 시작 |

충돌은 "마지막 수정 시간"이 아니라 **revision(저장 번호)**으로 판단해요. 기기가 알고 있는 번호와 서버 번호가 다르면 다른 기기에서 저장이 끼어든 것이라 덮어쓰지 않아요.
다른 기기의 데이터를 덮어쓸 때는 서버가 이전 데이터를 `game_save_backups`에 최근 20개까지 보관해요.

## 문제 해결

- **로그인 버튼이 안 보여요** → `config.js`의 두 값이 비어 있어요.
- **"메일 인증을 먼저 완료해 주세요"** → 가입 확인 메일의 링크를 누르세요(스팸함 확인).
- **메일 링크를 누르면 localhost로 가요** → 2단계의 Site URL / Redirect URLs를 Vercel 주소로 바꾸세요.
- **"⚠ 동기화 실패"** → `supabase.sql`을 실행했는지 확인하세요. 길드 화면의 동기화 표시를 누르면 자세한 오류가 나와요.
